# DSH-Folk

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**DSH-Folk** —— FolkPatch UI 的 GPL 分支 · 为 DeepSeek Harness 打造的移动端界面。

本项目是 **[FolkPatch](https://github.com/LyraVoid/FolkPatch)** 的修改版本（Modified Version），将其精致、流畅的 Android UI 代码适配为 **DeepSeek Harness（`dsh`）** 的前端界面，让 AI 智能体在移动端获得原生级的交互体验。

> ⚖️ **法律声明**：DSH-Folk 是 FolkPatch 的衍生作品，遵循 **GNU General Public License v3.0** 开源。任何对本项目的分发、修改，都必须同样以 GPL-3.0 公开源代码。

## ✨ 特性

- **🎨 原汁原味的 FolkPatch UI**：完整继承其流畅动效、壁纸感知主题与精致控件
- **📱 移动端原生交互**：针对 Android 触控优化的手势与反馈
- **🔌 DSH 生态兼容**：完整接入 DeepSeek Harness “一切皆插件” 的智能体框架
- **🔄 持续跟随上游**：定期合并 FolkPatch 主线的 UI 更新

## 🚀 快速开始

### 环境要求
- Android 7.0 或更高版本
- 已部署 DeepSeek Harness（`dsh`）运行时环境

### 安装步骤

1. 从 [Releases](https://github.com/your_github_name/DSH-Folk/releases) 下载最新 APK
2. 在 Android 设备上安装
3. 打开应用，自动连接本机 `dsh` 服务
4. 开始体验
